# Bookshelf
Проект книжная полка

## Суть
Web приложение, для авторизованных пользователей, которые могут икать книги через Google Books API, сохранять их в личный профиль (Firebase) и отслеживать прогресс.

## Стек технологий
- Фреймворк - React + SCSS (для стилизации)
- Маршрутизация - React Router
- Кастомные всплывающие уведомления - React Hot Toast
- База данных, как сервис - Firebase
- Внешние API - Google Books API
- Типизация приложения - TypeScript
- Сборщик приложения - Vite
- Доступ к внешним API - Axios

## Функционал
1. Модуль авторизации
- страницы входа и авторизации
- вход по email + password или Google-вход, или AppleId
- защита маршрутов
2. Интеграция с Google Books API
- пользователь вводит название книги, а frontend делает Axios запрос к Google Books API
- frontend делает рендер карточек найденных книг
- при нажатии на добавить, front добавляет в Firebase книгу
3. Синхронизация с БД
- при срабатывании Drag&Drop события (переносе с полки на полку), мгновенно происходит запрос к Firebase
- при прогрузке главной страницы, React запрашивает из Firestore только те книги, которые принадлежат текущему uid
- каждое действие сопровождается React Hot Toast

## Структура страниц
1. / - главная страница. Доступна только авторизованным лицам
2. /login - страница входа/авторизации. Доступна только неавторизованным лицам
3. /search - поиск книг в Google Books
4. /books/:id - сама книга
5. /book/:id - страница в книге
